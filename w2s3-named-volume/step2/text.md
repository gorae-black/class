이제 VM(이 터미널)의 `~/html/index.html` 파일을 새로운 내용으로 덮어씁니다. 컨테이너를
재시작하지 않고 파일만 바꿔서, 웹 화면이 어떻게 되는지 확인해보겠습니다.

```
echo '<h1>Updated!</h1>' > ~/html/index.html
curl localhost:8080
```

**실행 결과 예시**

```
<h1>Updated!</h1>
```

컨테이너를 재시작하지 않았는데도 "Updated!"로 바뀐 것이 보이면 성공입니다. Bind Mount는 파일을
복사하는 게 아니라 연결하는 것이기 때문에, VM의 파일과 컨테이너가 보는 파일이 사실은 완전히
같은 파일입니다.
