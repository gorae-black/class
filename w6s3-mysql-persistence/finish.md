**오늘 배운 내용 정리**

첫째, PVC를 Pod의 volumeMounts에 연결하면 컨테이너 데이터가 hostPath에 실제로 저장됩니다.
둘째, Pod가 재생성되어도 PV에 저장된 데이터는 그대로 유지됩니다.

**다음 순서**

개인 로컬 VM에서도 동일한 절차로 MySQL을 배포하고 영속성을 검증해보세요. Pod 삭제 **전**의 SELECT
결과와, 삭제 **후** 새 Pod에서의 SELECT 결과를 비교해 데이터가 동일한지 확인하면 됩니다.

오늘이 6주차 마지막 시간이니, 1차시(ConfigMap/Secret)·2차시(PV/PVC)·3차시(오늘, MySQL 영속성
검증) 실습을 한 번에 정리해보세요.

6주차 수고 많으셨습니다! 설정 분리(ConfigMap/Secret)부터 데이터 영속성(PV/PVC)까지, MySQL을 직접
다루며 K8s 상태 관리를 완주하셨습니다. 다음 7주차에서는 여러 Service를 하나의 진입점으로 묶어주는
**Ingress**, 그리고 K8s가 장애 상황에서 스스로 복구하는 **자가치유** 능력을 배웁니다.
