**다음 순서 (필수 제출)**

개인 로컬 VM(cloud-lab)에서 동일하게 `app.py`와 `Dockerfile`을 작성하고, `docker build` →
`docker run` → `curl localhost:5000`까지 실행해서 `Hello, Cloud!`가 나오는 것을 확인한 뒤
캡처해주세요.

그다음 이 두 파일(`app.py`, `Dockerfile`)을 GitHub 저장소(`cloud-lab`)에 `git add`,
`git commit`, `git push`로 올려주세요. Git 명령어가 익숙하지 않다면 강의 자료의
`06_로컬VM_과제복습` 폴더에 있는 단계별 가이드를 참고하세요.

캡처 결과와 GitHub 저장소 링크(`https://github.com/{본인아이디}/cloud-lab`)를 LMS 과제
게시판에 제출해주세요. GitHub 저장소는 반드시 **Public**으로 설정되어 있어야 채점자가 확인할 수
있습니다.

오늘 필수 제출물은 여기까지입니다. Docker Hub에 이미지를 올리는 것은 다음 3차시의 선택 심화
과제이니, 오늘은 부담 갖지 않으셔도 됩니다.
