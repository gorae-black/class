이미지를 컨테이너로 실행하고, `curl`로 실제 응답이 오는지 확인합니다. `-p 5000:5000`은 컨테이너의
5000번 포트를 이 터미널의 5000번 포트로 연결합니다.

```
docker run -d -p 5000:5000 myflask:v1
```

컨테이너가 뜬 뒤 `curl`로 `/`에 접속해봅니다.

```
curl localhost:5000
```

**실행 결과 예시**

```
Hello, Cloud!
```

`Hello, Cloud!`가 그대로 출력되면 성공입니다. `docker ps`로도 컨테이너가 `Up` 상태인지 다시 한 번
확인해보세요.

```
docker ps
```

여러분이 직접 작성한 코드가 이미지가 되고, 그 이미지로 컨테이너가 실행되어 실제로 응답을 준다는
전체 흐름을 오늘 처음부터 끝까지 경험한 것입니다.
