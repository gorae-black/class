## 클라우드인프라관리 3주차 2차시 실습

지난 1차시에서 `Dockerfile` 문법을 배웠습니다. 오늘은 그걸 실제로 써먹어 볼 차례입니다. 여러분이
직접 작성한 아주 간단한 Python Flask 앱을 `Dockerfile`로 빌드해서 이미지로 만들어봅니다.

앱은 딱 `/`라는 주소로 접속하면 `Hello, Cloud!`라는 문자열 하나를 응답하는 게 전부입니다. 이 코드를
외울 필요는 전혀 없습니다 — 오늘 목표는 파이썬 문법을 익히는 게 아니라, "내가 만든 앱을 Dockerfile로
이미지화하는 전체 흐름"을 경험하는 것입니다.

**시간 제한 안내**

이 세션은 **60분 제한**이 있습니다. 실습 중 시간이 종료되어도 당황하지 마세요 — 만약 중간에 끊기면
LMS의 링크로 다시 접속해 이어서 진행하면 됩니다.

**이 실습은 이번 주차 정식 VM 과제입니다.** 여기서 먼저 연습해보고, 이후 개인 로컬 VM에서 동일하게
실행한 결과를 GitHub 저장소 push와 함께 제출해야 합니다. (Docker Hub push는 다음 3차시 필수
과제이니, 오늘은 로컬 build·run·curl 확인까지만 하면 됩니다.)

준비되셨으면 다음 단계로 진행해주세요.
