# 1주차 1차시 — 클라우드 개념·가상화 퀴즈 (OX·단답형 8문항)

- 범위: 1주차 1차시(클라우드 컴퓨팅 패러다임, 가상화 기술, 터미널 기초 명령어)
- 형식: OX 5문항 + 단답형 3문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~5번)

**1.** 온프레미스 방식은 회사가 서버를 직접 구매해서 자체 전산실에서 운영하는 방식이다. ( )

**2.** 클라우드 컴퓨팅의 "종량제 과금"은 매달 고정된 요금을 미리 내는 방식이다. ( )

**3.** 가상화에서 하이퍼바이저는 물리 자원(CPU, 메모리, 디스크)을 나눠서 각 VM에 배분해주는
소프트웨어이다. ( )

**4.** VM은 여러 개를 동시에 띄워도 서로 다른 OS(Windows, Linux 등)를 각각 가질 수 없다. ( )

**5.** `nproc`, `free -h` 명령으로 확인한 CPU 코어 수와 메모리 용량은 실제 내 PC의 사양이 아니라
가상 환경에 할당된 만큼만 보여준다. ( )

## 단답형 문제 (6~8번)

**6.** 인터넷을 통해 서버·저장공간·네트워크 같은 컴퓨팅 자원을 필요한 만큼 빌려 쓰는 방식을
무엇이라고 부르나요?

**7.** 강의에서 소개한 VM 방식의 세 가지 한계를 각각 한 단어로 쓰세요.

**8.** 지금 내가 터미널에 어떤 계정으로 접속해 있는지 확인하는 명령어는 무엇인가요?

---

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | O | 온프레미스는 "현장에 있다"는 뜻으로, 회사가 서버를 직접 구매·운영하는 방식이다. |
| 2 | X | 종량제 과금은 전기요금처럼 **쓴 만큼만** 지불하는 방식이다. 고정 요금이 아니다. |
| 3 | O | 하이퍼바이저는 물리 서버 자원을 나눠서 그 위의 여러 VM에게 배분해주는 역할을 한다. |
| 4 | X | VM은 각자 완전한 Guest OS를 가지므로, 한 물리 서버 위에서 Windows VM과 Linux VM을 동시에 띄울 수 있다. |
| 5 | O | 이 값들은 실제 PC 사양이 아니라, 가상화 기술이 나눠준 딱 그만큼의 자원만 보여준다. |
| 6 | 클라우드 컴퓨팅 | 자원을 직접 사는 대신 필요한 만큼 빌려 쓰는 방식이다. |
| 7 | 무겁다(용량이 큼) / 느리다(부팅이 오래 걸림) / 낭비된다(자원 중복) | VM은 완전한 OS를 통째로 담고 있어 무겁고, 매번 OS를 부팅해야 해서 느리며, 여러 VM을 띄우면 자원이 중복 소모된다. |
| 8 | `whoami` | 현재 로그인된 계정 이름을 출력하는 명령어다. |
