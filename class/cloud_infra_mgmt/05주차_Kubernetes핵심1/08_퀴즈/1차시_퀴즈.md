# 5주차 1차시 — Service 등장 배경 퀴즈 (OX·단답형 6문항)

- 범위: 5주차 1차시(Pod IP의 문제, Service 개념, Label Selector)
- 형식: OX 4문항 + 단답형 2문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~4번)

**1.** Pod가 삭제되었다가 Deployment에 의해 다시 생성되면, 새 Pod는 이전과 동일한 IP를 그대로
이어받는다. ( )

**2.** Service는 자신만의 고정된 IP와 이름을 가지며, 뒤에 있는 Pod가 바뀌어도 그 주소는 그대로
유지된다. ( )

**3.** Service는 라벨(label)을 이용해 어느 Pod로 트래픽을 전달할지 찾아낸다. ( )

**4.** 4주차에 작성한 deployment.yaml의 Pod 템플릿에는 라벨이 들어 있지 않았다. ( )

## 단답형 문제 (5~6번)

**5.** Pod가 여러 개(`replicas: 2` 등)이고 재생성될 때마다 IP가 바뀌는 상황에서, 클라이언트가 항상
같은 주소로 접속할 수 있게 해주는 K8s 오브젝트는 무엇인가요?

**6.** Service가 Pod를 찾을 때 Pod의 IP가 아니라 무엇을 기준으로 찾는지 쓰세요.

---

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | X | 새로 생성된 Pod는 이전과 **다른 IP**를 받는다. 이 때문에 Pod IP는 불안정하다. |
| 2 | O | Service는 고정된 IP·이름을 가지며, 뒤의 Pod가 바뀌어도 Service 주소는 그대로 유지된다. |
| 3 | O | Service는 Pod에 붙은 라벨(예: `app: myapp`)을 selector로 지정해 해당 라벨이 붙은 Pod 전부를 찾아 연결한다. |
| 4 | X | 4주차 deployment.yaml에도 `app: myapp` 같은 라벨이 이미 들어 있었다. Service는 이 라벨을 그대로 활용한다. |
| 5 | Service | Service는 고정된 진입점 역할을 하여 Pod IP가 바뀌어도 항상 같은 주소로 접속할 수 있게 해준다. |
| 6 | 라벨(Label) | Service는 Label Selector로 라벨이 일치하는 Pod들을 자동으로 찾아 연결한다. |
