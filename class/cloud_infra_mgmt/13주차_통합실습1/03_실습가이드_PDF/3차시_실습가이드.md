# 13주차 3차시 실습가이드

## 개요

2차시까지는 Build Now 버튼을 눌러서 각 단계가 개별적으로 성공하는지 확인했습니다. 오늘은 사람이
버튼을 누르지 않고, **코드 수정 → git push**만으로 전체 파이프라인이 저절로 돌아가는지 확인하는
최종 검증(End-to-End 테스트)입니다. 이번 차시는 13주차의 마지막 시간으로, 1~3차시 실습을 종합해서
제출합니다.

- 소요시간: 50분 (개념 설명 15분 + VM 실습 30분 + 결과 정리 5분, Killercoda 없음)

## VM 실습

### 1. E2E 테스트 — 코드 수정 후 자동 배포 확인

1. `app.py`의 챗봇 응답 문구를 한 줄 수정합니다.
2. `git push origin main`을 실행합니다.
3. **아무것도 누르지 말고** 최대 1~2분 기다립니다.
4. Jenkins Build History에 자동 빌드가 새로 생기는지 확인합니다.
5. 빌드가 성공하면 `curl $(minikube service chatbot --url)`로 실제 응답이 바뀐 것을 확인합니다.

오늘의 최종 목표는 `app.py`의 챗봇 응답 문구 하나를 바꾸고 push했을 때, 실제 챗봇의 응답이 바뀌는
것까지 직접 확인하는 것입니다.

### 2. 문제 발생 시 대응 — 트러블슈팅 체크리스트

만약 실패한다면, 실패한 stage를 확인하고 아래 체크리스트를 참고해서 원인부터 좁혀나갑니다.

Stage별로 자주 생기는 문제는 다음과 같습니다.

| Stage | 자주 발생하는 문제 |
|---|---|
| Checkout | 저장소 URL 오타, 저장소가 Private으로 설정된 경우 |
| Build | Dockerfile 문법 오류, 이미지 이름 오타 |
| Push | `dockerhub-cred`를 등록하지 않았거나 Docker Hub 아이디를 잘못 입력한 경우 |
| Deploy | Deployment나 컨테이너 이름이 실제 YAML과 다름, minikube가 꺼져있는 경우 |

막혔을 때 진단하는 순서는 다음과 같습니다.

1. Jenkins Job의 **Console Output**에서 빨간 글씨(오류 메시지)를 먼저 읽습니다.
2. 어느 stage에서 멈췄는지 **Stage View**의 색깔로 확인합니다.
3. 오류 메시지를 그대로 검색하거나, VM 터미널에서 **같은 명령을 손으로 직접 실행**해서 원인을
   재현해봅니다.

`docker ps`, `kubectl get pods`, `kubectl describe pod`처럼 실제 상태를 직접 확인하는 명령어들을
적극적으로 활용하세요. 해결되면 다시 코드를 수정해서 `git push`로 재검증합니다. 이 반복 과정 자체가
실전 트러블슈팅입니다.

## 제출 안내

- 코드 수정 전/후 챗봇 응답 curl 결과를 각각 캡처합니다(변경이 확인되어야 합니다).
- Jenkins Build History에서 자동으로 트리거된 빌드 이력을 캡처합니다.
- 오늘이 13주차 마지막 시간이므로, 1차시(아키텍처 설계 흐름도)·2차시(파이프라인 구축 결과)·
  3차시(오늘, E2E 테스트 결과) 실습을 종합해서 제출합니다.
- 겪었던 트러블슈팅 사례를 최소 1가지, 원인과 해결 방법과 함께 기록해서 제출합니다.

### 참고 — 자주 묻는 질문

- 1~2분을 기다려도 빌드가 새로 생기지 않는다면, Poll SCM 설정(`* * * * *`)이 제대로 저장됐는지,
  `git push`가 실제로 원격 저장소에 반영됐는지(`git log`, GitHub 웹사이트 확인)를 먼저 점검합니다.
- Deploy까지는 성공했는데 챗봇 응답이 그대로라면, `kubectl rollout status deployment/chatbot`으로
  롤아웃이 완료됐는지 확인하고, `${BUILD_NUMBER}` 태그가 매번 바뀌는지(이전 이미지가 캐시되어
  재사용되고 있지 않은지) 점검합니다.
- 13~14주차는 시간 제약 없는 실습 구간이므로, 수업 시간에 못 끝냈다면 LMS Q&A와 오류FAQ를 참고해
  이어서 진행합니다. 다음 14주차는 13주차에 완성된 파이프라인을 전제로 하니, 늦더라도 13주차를
  반드시 완료해야 합니다.
