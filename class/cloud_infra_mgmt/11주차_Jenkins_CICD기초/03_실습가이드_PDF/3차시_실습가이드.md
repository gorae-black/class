# 11주차 3차시 실습가이드

## 개요

지난 2차시에서 멈췄던 초기 비밀번호 입력 화면부터 이어서, 오늘은 플러그인 설치와 관리자 계정
생성으로 초기 설정을 마무리하고, 처음으로 나만의 Freestyle Job을 만들어 Build Now로 실행합니다.
이번 차시가 11주차의 마지막이며, 이를 마치면 13주차 대통합 실습을 위한 베이스캠프가 완성됩니다.
소요시간은 개념 설명 약 25분 + VM 실습입니다.

## VM 실습

### 1. 초기 설정 마법사 완료

지난 2차시에서 초기 관리자 비밀번호를 입력한 화면 다음부터 진행합니다.

1. **Install suggested plugins**를 선택합니다. Git 연동, Pipeline 실행 등 앞으로 쓸 기본 플러그인이
   자동으로 설치됩니다.
2. 설치가 끝나면 나오는 화면에서 관리자 계정(아이디, 비밀번호, 이메일)을 생성합니다.
3. Jenkins URL을 확인하는 화면까지 지나가면 초기 설정이 끝납니다.

> **중요**: 여기서 만든 관리자 계정은 오늘로 끝이 아니라 12주차, 13주차까지 계속 사용합니다.
> 비밀번호를 잊어버리면 컨테이너 내부 파일을 다시 확인해야 하는 번거로움이 있으니, 개인 메모장 등에
> 안전하게 기록해두세요.

### 2. Freestyle Job 만들기 — hello-jenkins

1. Jenkins 대시보드에서 **New Item**을 클릭합니다.
2. **Freestyle project**를 선택하고, Job 이름을 `hello-jenkins`로 입력합니다.
3. **Build Steps**에서 **Execute shell**을 추가하고, 아래 명령어를 입력합니다.

   ```bash
   echo "Hello, Jenkins! Build number: $BUILD_NUMBER"
   ```

   `$BUILD_NUMBER`는 Jenkins가 자동으로 채워주는 환경변수로, 이 Job이 몇 번째로 실행됐는지를
   나타냅니다.

4. 저장한 뒤 **Build Now**를 클릭합니다.
5. Build 이력에서 방금 실행한 빌드를 클릭하고 **Console Output**을 확인합니다. echo 결과와 빌드
   번호가 함께 출력되는 것을 볼 수 있습니다.

> Build Now를 눌렀는데 반응이 없어 보이면, 대시보드 왼쪽 하단이나 Build History에서 진행 중인
> 빌드(회전하는 원 아이콘)를 확인하세요. 빌드가 끝나면 파란 원(성공) 또는 빨간 원(실패)으로
> 표시됩니다.

## 제출 안내

- 개인 VM의 Jenkins에서 초기 설정 마법사(플러그인 설치·관리자 계정 생성)를 완료합니다.
- `hello-jenkins` Freestyle Job을 만들고 Build Now를 실행한 뒤, Console Output에 echo 결과가
  출력된 화면을 캡처해서 제출합니다.
- **11주차 종합 제출**: 오늘이 11주차 마지막 시간이므로, 1차시(개념)·2차시(Jenkins 설치)·3차시
  (오늘, 첫 Job 실행) 실습 결과를 종합해서 LMS 과제 게시판에 제출합니다.
