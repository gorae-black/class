# 11주차 1차시 실습가이드

## 개요

CI(지속적 통합)는 코드가 바뀔 때마다 자동으로 빌드·테스트하는 것, CD(지속적 배포)는 그 결과물을
자동으로 실제 서비스 환경까지 배포하는 것입니다. Jenkins는 이 CI/CD를 실행해주는 자동화 서버로,
Job(작업 정의) · Build(실행 결과) · Plugin(기능 확장 부품)으로 구성됩니다. 오늘은 개념과 Jenkins UI
구조를 익히는 시간으로, 소요시간은 개념 설명 위주 약 25분입니다.
