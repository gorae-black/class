# 11주차 3차시 — 플러그인·관리자 계정·첫 Job 퀴즈

- 범위: 11주차 3차시(초기 설정 마법사, Freestyle Job)
- 형식: OX 5문항 + 단답형 3문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~5번)

**1.** Jenkins 초기 설정 마법사에서 'Install suggested plugins'를 선택하면 Git 연동, Pipeline 실행
등 기본 플러그인이 자동으로 설치된다. ( )

**2.** Freestyle Job은 화면에서 클릭으로 설정하는 방식이 아니라, 코드(Jenkinsfile)로 작성하는
방식이다. ( )

**3.** `$BUILD_NUMBER`는 사용자가 직접 값을 입력해야 하는 변수로, Jenkins가 자동으로 채워주지
않는다. ( )

**4.** Build Now를 클릭하면 Build 이력에 실행 결과(Console Output)가 남는다. ( )

**5.** 11주차 3차시는 11주차의 마지막 차시이며, 1~3차시 실습 결과를 종합해서 제출해야 한다. ( )

## 단답형 문제 (6~8번)

**6.** Job을 만드는 가장 간단한 방법으로, 오늘 실습에서 만든 Job의 종류(타입) 이름은 무엇인가요?

**7.** 오늘 실습에서 만든 Job의 이름은 무엇인가요?

**8.** Job 설정 화면에서 실행할 셸 명령어를 입력하는 Build Steps 항목의 이름은 무엇인가요?

---

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | O | 'Install suggested plugins'를 선택하면 Git 연동, Pipeline 실행 등 앞으로 쓸 기본 플러그인이 자동 설치된다. |
| 2 | X | 반대다. Freestyle Job은 화면에서 **클릭**으로 설정하는 방식이고, 코드로 작성하는 방식은 다음 주에 배울 Pipeline(Jenkinsfile)이다. |
| 3 | X | `$BUILD_NUMBER`는 Jenkins가 **자동으로** 채워주는 환경변수로, 해당 Job이 몇 번째로 실행됐는지를 나타낸다. |
| 4 | O | Build Now를 클릭하면 Build 이력에 실행 결과(Console Output)가 남는다. |
| 5 | O | 이번 차시는 11주차의 마지막이며, 1~3차시 실습 결과를 종합해서 LMS 과제 게시판에 제출해야 한다. |
| 6 | Freestyle project(Freestyle Job) | Job을 만드는 가장 간단한 방법이 Freestyle Job이다. |
| 7 | hello-jenkins | 오늘 실습에서 만든 Job 이름은 `hello-jenkins`다. |
| 8 | Execute shell | Build Steps에 'Execute shell'을 추가하고 실행할 명령어를 입력한다. |
