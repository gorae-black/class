# 2주차 1차시 — 컨테이너 명령어 심화 퀴즈 (OX·단답형 7문항)

- 범위: 2주차 1차시(컨테이너 생명주기, `logs`·`exec`)
- 형식: OX 4문항 + 단답형 3문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~4번)

**1.** `docker run`은 `docker create`와 `docker start`를 합친 명령어이다. ( )

**2.** `docker stop`으로 컨테이너를 멈추면, 컨테이너 자체와 그 안의 파일이 즉시 삭제된다. ( )

**3.** `docker ps`(옵션 없이)는 정지된 컨테이너까지 포함해 모든 컨테이너를 보여준다. ( )

**4.** `docker rm -f`는 컨테이너가 실행 중이어도 강제로 바로 삭제한다. ( )

## 단답형 문제 (5~7번)

**5.** 정지된 컨테이너를 완전히 삭제하지 않고 다시 실행 상태로 되돌리는 명령어는
무엇인가요?

**6.** 실행 중인 컨테이너가 지금까지 출력한 로그를 확인하는 명령어는 무엇인가요?

**7.** 실행 중인 컨테이너 내부로 직접 들어가서 명령어를 치고 싶을 때 사용하는 명령어를
쓰세요. (예: `docker exec -it {이름} bash`)

---

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | O | `docker run`은 컨테이너를 만들기만 하는 `create`와, 실제로 실행시키는 `start`를 한 번에 수행하는 명령어다. |
| 2 | X | `docker stop`은 컨테이너를 멈출 뿐, 컨테이너와 그 안의 파일은 사라지지 않는다. 완전히 지우려면 `docker rm`을 써야 한다. |
| 3 | X | `docker ps`는 기본적으로 실행 중(Running)인 컨테이너만 보여준다. 정지된 것까지 보려면 `-a` 옵션이 필요하다. |
| 4 | O | `docker rm -f`는 실행 중이어도 강제로 완전히 삭제하며, 되돌릴 수 없다. |
| 5 | `docker start {이름}` | 정지된 컨테이너를 다시 실행 상태로 되돌리는 명령어다. 이미지를 새로 받거나 컨테이너를 새로 만들지 않는다. |
| 6 | `docker logs {이름}` | 컨테이너가 지금까지 출력한 로그를 보여준다. "창문 너머로 구경하기"에 비유된다. `-f` 옵션을 붙이면 실시간으로 계속 지켜볼 수 있다. |
| 7 | `docker exec -it {이름} bash` | 컨테이너 "안으로" 직접 들어가는 명령어다. "문 열고 직접 들어가기"에 비유된다. 나올 때는 `exit`을 입력한다. |
