# 14주차 3차시 — 자가치유 라이브 검증과 전체 회고 퀴즈 (OX·단답형 10문항)

- 범위: 14주차 3차시(자가치유 라이브 검증, HPA+자가치유의 관계, 학기 전체 회고)
- 형식: OX 6문항 + 단답형 4문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~6번)

**1.** 자가치유(Self-Healing)는 7주차에서 배운 내용이다. ( )

**2.** 부하가 걸려 Pod가 여러 개로 늘어난 상태에서 Pod 하나를 강제로 삭제하면, Deployment가
즉시 새 Pod로 그 자리를 채운다. ( )

**3.** Pod 하나가 삭제되는 동안에는 나머지 Pod가 있어도 서비스(curl 응답)가 완전히
끊긴다. ( )

**4.** Scale-out(HPA)과 자가치유(Self-Healing)가 함께 동작하면, 트래픽 폭주와 장애 두
가지 위기 모두에서 서비스가 스스로 살아남을 수 있다. ( )

**5.** 이번 학기 실습은 VM 환경 구성(0주차) → Docker(1~3주) → Kubernetes(4~7주) →
Terraform(9~10주) → Jenkins(11~12주) → 통합(13~14주) 순으로 진행되었다. ( )

**6.** 15주차는 추가 통합 실습 주차이며, 시험은 16주차에 치러진다. ( )

## 단답형 문제 (7~10번)

**7.** 특정 이름의 Pod를 강제로 삭제하는 명령어를 쓰세요. (Pod 이름은 `{파드이름}`으로
표기)

**8.** 삭제된 Pod 대신 새 Pod가 생성되는 과정을 실시간으로 관찰할 수 있는 명령어를
쓰세요.

**9.** 이번 학기 실습에서 배운 기술을 등장 순서대로 나열하세요(0주차부터 14주차까지).

**10.** 14주차 종합 제출에 포함해야 할 세 개 차시의 실습 내용을 각각 쓰세요.

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | O | 자가치유는 7주차에 배운 원리이며, 오늘은 이를 '부하가 걸린 실전 상황'에서 검증한다. |
| 2 | O | Deployment는 replicas 개수를 유지하려 하므로, Pod가 삭제되면 즉시 새 Pod를 만들어 채운다. |
| 3 | X | Pod 하나가 죽어도 나머지 Pod들이 요청을 처리하고 있으므로, 서비스는 완전히 끊기지 않고 계속 살아있어야 정상이다. |
| 4 | O | 이 둘이 함께 있으면 '트래픽 폭주'와 '장애' 두 위기 모두에서 서비스가 사람 개입 없이 스스로 살아남는다. |
| 5 | O | 0단계(VM, 0주차) → 1단계(Docker, 1~3주) → 2단계(Kubernetes, 4~7주) → 3단계(Terraform, 9~10주) → 4단계(Jenkins, 11~12주) → 5단계(통합, 13~14주) 순이다. |
| 6 | X | 다음 15주차는 기말고사이다. 14주차가 사실상 실습 수업의 마지막이다. |
| 7 | `kubectl delete pod {파드이름}` | 강제로 Pod를 삭제해 자가치유를 트리거하는 명령이다. |
| 8 | `kubectl get pods -w` | Terminating에서 새 Pod가 생성되는 과정을 실시간으로 확인할 수 있다. |
| 9 | VM 환경 구성(0주차) → Docker(1~3주) → Kubernetes(4~7주) → Terraform(9~10주) → Jenkins(11~12주) → 통합(13~14주) | 다섯 단계를 거쳐 하나의 파이프라인으로 통합했다. |
| 10 | 1차시(HPA 설정), 2차시(부하 테스트), 3차시(자가치유) | 14주차 마지막 시간에 세 차시 실습을 종합해서 LMS 과제 게시판에 제출한다. |
