# 10주차 2차시 — Terraform Cloud 계정·워크스페이스 생성 퀴즈 (OX·단답형 10문항)

- 범위: 10주차 2차시(계정 가입, 워크스페이스, terraform login, cloud 블록)
- 형식: OX 6문항 + 단답형 4문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~6번)

**1.** Terraform Cloud의 조직(Organization) 이름은 전역에서 고유하지 않아도 상관없다. ( )

**2.** GitHub 계정으로 Terraform Cloud에 가입하면, 다음 3차시의 GitHub 연동 과정이 더 수월해진다. ( )

**3.** 워크스페이스 안에는 State, 변수, 실행 이력(Runs)이 함께 관리된다. ( )

**4.** `terraform login`으로 발급받은 토큰은 비밀번호와 같으므로 다른 사람과 공유하면 안 된다. ( )

**5.** `main.tf`의 `cloud` 블록에는 `workspaces` 항목으로 워크스페이스 이름을 지정한다. ( )

**6.** 2차시 VM 실습에서는 워크스페이스 생성뿐 아니라 `terraform apply`까지 실행해야 한다. ( )

## 단답형 문제 (7~10번)

**7.** VM 터미널에서 Terraform CLI와 Terraform Cloud 계정을 연동할 때 사용하는 명령어는 무엇인가요?

**8.** 오늘 실습에서 만드는 워크스페이스의 이름은 무엇인가요?

**9.** `main.tf`의 `cloud` 블록 안에 지정해야 하는 두 가지 항목은 무엇인가요?

**10.** `terraform login` 실행 시 브라우저가 자동으로 열리지 않으면 어떻게 해야 하나요?

---

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | X | 조직 이름은 Terraform Cloud 전역에서 고유해야 하므로, 너무 흔한 이름은 이미 사용 중일 수 있다. |
| 2 | O | GitHub 계정으로 가입하면 다음 3차시의 GitHub 연동이 훨씬 수월해진다. |
| 3 | O | 워크스페이스는 하나의 인프라 단위를 관리하는 작업 공간으로 State, 변수, 실행 이력이 함께 들어있다. |
| 4 | O | 토큰은 비밀번호와 같은 역할을 하므로 공유하거나 코드에 남기면 안 된다. |
| 5 | O | `workspaces { name = "cloud-lab" }`처럼 워크스페이스 이름을 지정한다. |
| 6 | X | 2차시는 계정·워크스페이스 생성과 CLI 연동까지만 하고, `apply`는 아직 하지 않는다(3차시에 진행). |
| 7 | `terraform login` | 이 명령을 실행하면 브라우저가 열리며 토큰 인증이 진행되고, 발급된 토큰이 VM 로컬에 저장된다. |
| 8 | `cloud-lab` | 강의에서 사용하는 예시 워크스페이스 이름이다. |
| 9 | `organization`(조직 이름), `workspaces.name`(워크스페이스 이름) | 이 두 값으로 `terraform init` 시 State가 저장될 위치가 정해진다. |
| 10 | 터미널에 출력되는 URL을 복사해서 직접 브라우저 주소창에 붙여넣고 접속한다 | 원격 터미널 환경 등에서 브라우저가 자동으로 열리지 않을 때의 대처법이다. |
