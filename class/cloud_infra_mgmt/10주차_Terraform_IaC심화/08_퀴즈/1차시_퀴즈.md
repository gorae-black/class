# 10주차 1차시 — 원격 State와 Terraform Cloud 퀴즈 (OX·단답형 10문항)

- 범위: 10주차 1차시(로컬 State의 문제, Terraform Cloud 개념, 원격 실행)
- 형식: OX 6문항 + 단답형 4문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~6번)

**1.** 로컬 State 파일은 여러 사람이 함께 쓸 때 서로 State가 달라 충돌이 날 수 있다. ( )

**2.** Terraform Cloud를 사용하면 `plan`/`apply` 연산이 내 VM이 아니라 Terraform Cloud의 서버에서
실행된다. ( )

**3.** Terraform Cloud의 원격 실행 서버는 내 VM의 로컬 Docker 데몬에 자유롭게 접근할 수 있다. ( )

**4.** Terraform Cloud는 개인·소규모 팀을 위한 무료 플랜을 제공하지 않는다. ( )

**5.** 10주차 1차시 수업에서는 아직 Terraform Cloud 계정을 만들지 않았다. ( )

**6.** Terraform Cloud의 Runs 탭에서는 누가, 언제, 무엇을 바꿨는지 실행 이력을 확인할 수 있다. ( )

## 단답형 문제 (7~10번)

**7.** 로컬 State 방식이 가진 세 가지 문제를 모두 쓰세요.

**8.** Terraform Cloud가 대신 해주는 세 가지 기능을 모두 쓰세요.

**9.** 원격 실행을 그대로 쓰면 9주차에 썼던 어떤 Provider 예제를 사용할 수 없나요? 그 이유도 한
문장으로 쓰세요.

**10.** 다음 2차시에 실제로 만들 예정인 것 세 가지를 쓰세요.

---

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | O | 로컬 State는 여러 사람이 각자 다른 State를 가지게 되어 협업 시 충돌이 날 수 있다. |
| 2 | O | Terraform Cloud는 State 저장뿐 아니라 plan/apply 연산 자체도 자신의 서버에서 원격 실행한다. |
| 3 | X | 원격 실행 서버는 학생 VM의 로컬 Docker 데몬에 접근할 방법이 전혀 없다. |
| 4 | X | 개인·소규모 팀용 무료 플랜이 있으며, 이 과목 실습 범위에서는 무료 플랜으로 충분하다. |
| 5 | O | 1차시는 개념 설명 중심이며, 계정 가입은 다음 2차시에 진행한다. |
| 6 | O | Runs 탭에서 실행 이력(누가 언제 무엇을 바꿨는지)을 전부 기록하고 조회할 수 있다. |
| 7 | 협업 문제, 보안 문제, 실행 환경 문제 | 여러 사람이 쓸 때 State 충돌(협업), State 안 민감정보 평문 노출(보안), VM이 꺼지면 apply 불가(실행 환경). |
| 8 | State 저장, 원격 실행, 실행 이력 | 여러 사람이 공유하는 원격 저장소에 State 보관, plan/apply를 Terraform Cloud 서버에서 실행, Runs 탭에 실행 이력 기록. |
| 9 | `docker`(`docker_container`) 예제 — 원격 서버가 학생 VM의 Docker 데몬에 접근할 수 없어 "Cannot connect to the Docker daemon" 오류가 나기 때문 | 원격 실행은 Terraform Cloud 서버에서 이뤄지므로 로컬 자원(Docker)에 접근이 불가능하다. |
| 10 | 계정, 조직(Organization), 워크스페이스(Workspace) | 2차시에는 Terraform Cloud 계정과 조직을 생성하고, 워크스페이스를 직접 만든다. |
