# 10주차 2차시 실습가이드
## Terraform Cloud 계정·워크스페이스 생성

## 개요

지난 시간에 Terraform Cloud가 무엇을 대신 해주는지 개념으로 배웠습니다. 오늘은 실제로 Terraform
Cloud 계정과 조직(Organization)을 만들고, State·변수·실행 이력을 관리하는 작업 공간인
**워크스페이스(Workspace)**를 직접 생성합니다. 그리고 `terraform login`으로 VM의 Terraform
CLI와 내 계정을 연동합니다.

- 소요시간: 개념 설명 25분(계정 준비 포함) + Killercoda 시연 감상 15분 + VM 안내 5분 + 결과
  제출 5분 (총 50분)
- 이번 차시는 이번 학기 세 번째 외부 서비스 가입(GitHub·Docker Hub에 이어)입니다.
- **오늘은 아직 `apply`는 하지 않습니다.** 실제 GitHub 연동과 원격 apply는 다음 3차시에
  진행합니다.

---

## 개념 시연 관찰 포인트 (수업 중 교수자 화면 공유)

오늘 Killercoda 시간은 교수자가 미리 만들어 둔 예시 워크스페이스 화면을 함께 살펴보는 시간입니다.

관찰 포인트:

- **Overview**, **States**, **Runs**, **Variables** 네 개 탭이 각각 무엇을 보여주는지
- 오늘은 실제 코드를 실행하기보다, 워크스페이스 UI 구조에 먼저 익숙해지는 데 초점

## VM 실습

개인 VM에서 아래 순서를 그대로 진행합니다.

### Step 1. Terraform Cloud 계정 만들기

1. `app.terraform.io`에 접속해서 이메일로 회원가입하거나, GitHub 계정으로 가입합니다.
   (다음 3차시에 GitHub 연동을 하게 되므로, 가능하면 **GitHub 계정으로 가입**하는 것을
   추천합니다 — 그 과정이 훨씬 수월해집니다.)
2. 이메일로 가입했다면 인증 메일을 확인해 이메일 인증을 완료합니다. 메일이 안 오면 스팸함을
   먼저 확인하세요.
3. 조직(Organization) 이름을 설정합니다. 개인 실습용이니 본인이 원하는 이름으로 만들면 됩니다.
   조직 이름은 Terraform Cloud 전역에서 고유해야 하므로, 너무 흔한 이름은 이미 사용 중일 수
   있습니다. 본인 이름이나 학번을 조합하면 충돌 가능성이 낮습니다.
4. 워크스페이스 생성 화면까지 진행되면 계정 가입이 완료된 것입니다.

### Step 2. 워크스페이스 생성

`cloud-lab`이라는 이름으로 워크스페이스를 하나 만듭니다. 이 워크스페이스 안에 앞으로 State,
변수, 실행 이력(Runs)이 함께 관리됩니다.

### Step 3. terraform login으로 CLI 연동

VM 터미널에서 아래 명령을 실행합니다.

```
terraform login
```

브라우저가 열리면서 토큰 인증이 진행됩니다(브라우저가 자동으로 열리지 않으면, 터미널에 출력되는
URL을 복사해서 직접 브라우저 주소창에 붙여넣어 접속하면 됩니다). 발급된 토큰은 VM 로컬에 자동으로
저장되고, 이후 `terraform` 명령을 실행하면 자동으로 내 계정으로 인증됩니다.

이 토큰은 비밀번호와 같은 역할을 하므로, 다른 사람과 공유하거나 코드에 그대로 남기지 않도록
주의하세요.

### Step 4. main.tf에 cloud 블록 작성

워크스페이스를 코드와 연결하기 위해 `main.tf`에 `cloud` 블록을 추가합니다.

```hcl
terraform {
  cloud {
    organization = "my-org"
    workspaces { name = "cloud-lab" }
  }
}
```

`organization` 자리에는 본인이 만든 실제 조직 이름을, `workspaces.name`에는 `cloud-lab`을
넣습니다. 이 블록이 있으면 `terraform init`을 실행할 때 State가 로컬이 아니라 지정한
워크스페이스에 저장됩니다.

**오늘은 아직 `apply`는 하지 마세요** — 다음 3차시에 GitHub 연동과 함께 진행합니다.
