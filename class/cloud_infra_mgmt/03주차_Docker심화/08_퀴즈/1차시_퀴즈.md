# 3주차 1차시 — Dockerfile 문법 퀴즈 (OX·단답형 8문항)

- 범위: 3주차 1차시(Dockerfile 문법, docker build)
- 형식: OX 5문항 + 단답형 3문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~5번)

**1.** `Dockerfile`은 이미지를 만드는 방법을 적어둔 설계도(레시피)이며, 그 자체가 실행 중인
컨테이너는 아니다. ( )

**2.** `docker build` 명령을 실행하면 `Dockerfile`에 적힌 내용을 바탕으로 실제 이미지가
만들어진다. ( )

**3.** `RUN`은 컨테이너가 시작될 때마다 실행되는 명령이다. ( )

**4.** `WORKDIR`는 컨테이너 안에서 앞으로의 작업을 진행할 폴더를 지정하는 명령어이다. ( )

**5.** `EXPOSE`는 컨테이너가 어떤 포트를 사용하는지 알려주는 역할이며, 그 자체로 포트를 외부에
연결해주지는 않는다. ( )

## 단답형 문제 (6~8번)

**6.** `Dockerfile`에서 어떤 이미지를 기반으로 시작할지 지정하는 명령어는 무엇인가요?

**7.** 내 컴퓨터(호스트)의 파일을 이미지 안으로 복사할 때 사용하는 명령어는 무엇인가요?

**8.** 현재 폴더의 `Dockerfile`을 읽어 `mynode`라는 이름, `v1`이라는 태그로 이미지를 빌드하는
명령어를 그대로 쓰세요.

---

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | O | `Dockerfile`은 "이런 순서로 이미지를 만들어라"라고 적어두는 설계도이며, `docker build`로 이 레시피를 실제 이미지로 바꾼다. |
| 2 | O | `docker build`는 `Dockerfile`을 한 줄씩 순서대로 실행하면서 레이어를 쌓아 이미지를 만든다. |
| 3 | X | `RUN`은 이미지를 만드는 동안(빌드 시점) 한 번 실행되는 명령이다. 컨테이너가 시작될 때마다 실행되는 것은 `CMD`다. |
| 4 | O | `WORKDIR`는 컨테이너 안에서 작업할 폴더를 지정한다. |
| 5 | O | `EXPOSE`는 이 컨테이너가 어떤 포트를 쓰는지 알려주는 문서 역할이다. |
| 6 | `FROM` | `FROM`은 어떤 이미지를 기반으로 시작할지 정한다(예: `python:3.11-slim`). |
| 7 | `COPY` | `COPY`는 호스트의 파일을 이미지 안으로 복사한다. |
| 8 | `docker build -t mynode:v1 .` | `docker build -t {이름}:{태그} .` 형식으로 현재 폴더(`.`)의 `Dockerfile`을 읽어 이미지를 빌드한다. |
