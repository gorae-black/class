# 3주차 2차시 — 계정 준비와 Flask 앱 빌드 퀴즈 (OX·단답형 8문항)

- 범위: 3주차 2차시(GitHub·Docker Hub 계정, Flask 앱 Dockerfile 빌드)
- 형식: OX 5문항 + 단답형 3문항
- 용도: LMS 자동채점 퀴즈. 수업 중 함께 풀고 바로 정답·해설을 확인합니다.

---

## OX 문제 (1~5번)

**1.** Docker Hub는 우리가 만든 이미지를 저장하고 공유할 수 있는 저장소이다. ( )

**2.** 오늘(2차시) 실습에서 Docker Hub에 이미지를 push하는 것까지가 필수 제출물에 포함된다. ( )

**3.** 오늘 만든 Flask 앱 이미지의 기반(`FROM`) 이미지는 `python:3.11-slim`이다. ( )

**4.** 컨테이너 실행 후 `curl localhost:5000`을 입력했을 때 `Hello, Cloud!`가 출력되면 Flask
앱이 컨테이너 안에서 정상적으로 응답하고 있는 것이다. ( )

**5.** GitHub에 `git push`할 때는 GitHub 로그인 비밀번호를 그대로 입력하면 항상 인증이 된다. ( )

## 단답형 문제 (6~8번)

**6.** 작성한 `app.py`와 `Dockerfile`로 `myflask`라는 이름, `v1`이라는 태그의 이미지를 빌드하는
명령어를 그대로 쓰세요.

**7.** 오늘 만든 `app.py`, `Dockerfile`을 제출하기 위해 올려야 하는 서비스는 무엇인가요
(1차시에 만들어 둔 `cloud-lab` 저장소가 있는 곳)?

**8.** 오늘 실습에서 필수 제출 대상이 아니라, 다음 3차시의 선택 심화 과제로 안내된 작업은
무엇인가요?

---

## 정답 및 해설

| 번호 | 정답 | 해설 |
|---|---|---|
| 1 | O | Docker Hub는 완성한 이미지를 저장하고 공유하는 저장소다. |
| 2 | X | 오늘 필수 제출물은 로컬 build·run·curl 확인까지이며, Docker Hub push는 다음 3차시의 선택 심화 과제다. |
| 3 | O | `FROM python:3.11-slim`으로 파이썬이 설치된 기반 이미지를 가져와 사용했다. |
| 4 | O | `curl localhost:5000`에 `Hello, Cloud!`가 그대로 출력되면 이미지·컨테이너·앱까지 전체 흐름이 정상 동작한 것이다. |
| 5 | X | GitHub는 2021년부터 비밀번호 대신 Personal Access Token(PAT) 또는 SSH 키를 요구한다. |
| 6 | `docker build -t myflask:v1 .` | 현재 폴더의 `Dockerfile`을 읽어 `myflask:v1` 이름으로 이미지를 빌드한다. |
| 7 | GitHub | `app.py`, `Dockerfile`을 GitHub 저장소(`cloud-lab`)에 `git add`, `git commit`, `git push`로 올려 제출한다. |
| 8 | Docker Hub push (이미지를 Docker Hub에 올리는 것) | 계정 마찰이 이번 실습의 핵심(Dockerfile 빌드)을 방해하지 않도록, Docker Hub push는 3차시의 선택 심화 과제로 분리되어 있다. |
