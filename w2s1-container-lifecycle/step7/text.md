`docker exec -it web2 bash`는 아예 그 컨테이너 "안으로" 직접 들어가는 명령어입니다. logs가
"창문 너머로 구경하기"라면, exec는 "문 열고 직접 들어가기"입니다.

```
docker exec -it web2 bash
```

**실행 결과 예시**

```
root@6b1f2a9c4e21:/#
```

프롬프트가 `root@{컨테이너ID}:/#` 형태로 바뀌면, 이제 여러분은 web2 컨테이너 내부에 들어와
있는 것입니다. 컨테이너 안에서 자유롭게 명령어를 쳐볼 수 있습니다. 다 확인했으면 `exit`을 쳐서
다시 원래 터미널로 나옵니다.

```
exit
```

프롬프트가 원래대로 돌아오면, 컨테이너 밖으로 정상적으로 빠져나온 것입니다.
